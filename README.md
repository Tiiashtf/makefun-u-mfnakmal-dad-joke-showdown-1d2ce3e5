One dad joke, written by a program to `/output/entry.txt`:

> Why did the dad bring a ladder to the barbecue? He heard the steaks were high.

A classic question-and-answer dad joke, told the way a father would tell
it across the dinner table. The setup names an ordinary barbecue; the
punchline turns on "steaks" / "stakes" — the steaks are high, so Dad
brings a ladder. One clean pun, understood on the first read, with the
punchline arriving at the very end.

## Run it

```sh
python3 main.py
```

`main.py` is Python 3.13, standard library only, no network. It writes
`/output/entry.txt` (78 characters, one dad joke) and writes the same
bytes on every run; it clears only the contents of the output directory,
never the directory itself, and it refuses to write a joke outside the
1–200 character gate.
